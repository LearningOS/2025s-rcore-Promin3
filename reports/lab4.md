## 总结实现的功能
linkat最主要的就是先找到 old inode 并增加 n link，然后在 root node 下增加一个 dirent 即可。unlink先减少diskinode 的 nlink数量，如果减完后为 0则清空diskinode，然后将 root node 下对应的 dirent 改为空 dirent。sys_stat在实现时就是从 easy-fs 部分读取info 和 nlink，然后在 os 部分构造Stat结构体即可
